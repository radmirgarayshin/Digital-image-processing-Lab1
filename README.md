## Задание

Реализовать на C++ вычисление статистических характеристик полутонового изображения:
- Гистограмма яркостей
- Среднее, дисперсия, квартили (Q1, Q2, Q3)
- Энтропия, энергия, коэффициенты асимметрии и эксцесса
- Матрица совместной встречаемости (GLCM) и её энергия
- Добавление аддитивного белого гауссового шума заданной дисперсии
- Вычисление PSNR

## Структура проекта

```
pngtest/
  pngtest.cpp     — главный файл (шаблон + вызов функций лаборатрной)

  PngProc.h       — библиотека  для чтения/записи PNG
  PngProc.cpp     — библиотека для чтения/записи PNG
  kotik.png       — тестовое изображение (фото, реальные данные)
  flat.png        — тест: однотонное изображение (все пиксели = 128)
  gradient.png    — тест: горизонтальный градиент 0→255
  checkerboard.png— тест: шахматка из блоков 0 и 255
libpng/           — библиотека libpng (предоставлена преподавателем)
zlib/             — библиотека zlib (предоставлена преподавателем)

```
